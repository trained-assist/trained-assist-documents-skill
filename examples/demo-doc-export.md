# Коммерческое предложение: Внедрение CRM-системы

## Исполнительное резюме

Предлагаем комплексное внедрение CRM-системы для автоматизации продаж, маркетинга и сервиса. Проект сократит цикл сделки на **30%**, увеличит конверсию лидов в клиенты на **25%** и даст полную видимость воронки для руководства.

## Текущие проблемы

| Проблема | Влияние на бизнес |
|----------|-------------------|
| Ручной ввод данных в таблицах | Потеря 15–20% лидов, ошибки в отчётности |
| Нет единой базы клиентов | Дубли контактов, конфликты между менеджерами |
| Отчёты собираются вручную за дни | Реактивное управление, нет прогнозов |
| История общения теряется при уходе людей | Потеря контекста, падение LTV |

## Предлагаемое решение

### Этап 1: Аудит и проектирование (2 недели)
- Интервью с ключевыми стейкхолдерами
- Карта процессов AS-IS / TO-BE
- Выбор платформы: amoCRM / Bitrix24 / Salesforce
- Техническое ТЗ на интеграции

### Этап 2: Внедрение ядра (4 недели)
- Настройка воронок, этапов, полей
- Миграция исторических данных (дедупликация)
- Интеграция с телефонией, почтой, мессенджерами
- Ролевой доступ и права

### Этап 3: Автоматизация и аналитика (3 недели)
- Триггеры: задачи, уведомления, вебхуки
- Дашборды: воронка, когорты, юнит-экономика
- Настройка отчётов для CEO / CRO / Head of Sales
- Обучение команды (админы + пользователи)

### Этап 4: Пилот и масштабирование (2 недели)
- Запуск на 1 отделе (10–15 человек)
- Сбор обратной связи, доработки
- Раскатка на всю компанию
- Передача в поддержку

## Интеграции (входят в базу)

| Система | Что синхронизируется |
|---------|---------------------|
| Телефония (МТТ, Билайн, Zadarma) | Звонки, записи, клик-ту-колл |
| Email (IMAP/SMTP, Gmail, Outlook) | Письма, вложения, трекинг открытий |
| Мессенджеры (WhatsApp Business, Telegram, VK) | Диалоги, лиды из чатов |
| Сайт / формы (Bitrix24, Tilda, Webflow) | Лиды, UTM-метки, события |
| 1С / ERP | Контрагенты, заказы, оплаты, остатки |
| Маркетинг (Яндекс.Метрика, GA4, Roistat) | Атрибуция, ROI каналов |

| Позиция | Стоимость (₽) | Примечание |
|---------|---------------|------------|

## Гарантии и SLA

- **Фиксированная цена** — нет скрытых доплат, изменения только через Change Request
- **Этапная оплата** — предоплата 50%, остальное по актам приёмки этапов
- **Гарантия 3 месяца** после приёмки: исправление багов внедрения за наш счёт
- **SLA поддержки** (опционально): 8×5, реакция 4 ч, решение 1 сутки — от 50 000 ₽/мес
