# deckgen — презентации из Markdown без LLM

`node deckgen.js deck.md [--out dir] [--name file] [--theme dark|light] [--accent HEX] [--no-pdf] [--png]`

На выходе: `.pptx` (открывается в Keynote/PowerPoint, редактируемый), `.pdf`, `.html`, опционально PNG-превью.
В stdout — JSON с путями и `warnings` (где текст не влез: разбей слайд или сократи). Рендер ~5 c на 10 слайдов.
LLM нужен только чтобы написать markdown. Раскладку, кегли, цвета и подсветку кода считает генератор.

## Формат
```
---                         ← шапка файла (необязательно)
title: Название
author: Имя
footer: Конференция · Имя   ← подпись внизу каждого слайда
theme: dark | light
accent: 2FD07A
---
```
Слайды разделяются строкой `---`.

| Разметка | Что получится |
|---|---|
| `# Заголовок` | титул (1-й слайд) или разделитель. `\n` — перенос строки |
| `[ТЕГ · Раздел]` | цветная метка над заголовком. ПРОТОТИП/ИТОГ/ГОТОВО — зелёный, ТЗ/ПЛАН — оранжевый, ИНЦИДЕНТ/РИСК — красный, ВОПРОС — синий |
| `## Заголовок` | заголовок слайда |
| текст, `- пункт`, `1. пункт`, отступ 2 пробела — подпункт | основной текст, кегль подбирается сам |
| ```` ```py подпись ```` | код с подсветкой (py/yaml). Один блок — во всю ширину, два — рядом |
| `### Карточка {green}` + строки/пункты ниже | карточки: 1–4 в ряд, 5–8 в два ряда. Цвет: green/red/orange/blue |
| код + карточки | код слева, карточки колонкой справа |
| код + пункты | код слева, пункты справа |
| `A -> B {red} -> C` | схема-цепочка из блоков со стрелками |
| `\| a \| b \|` | таблица (первая строка — шапка) |
| `> тезис` | крупный тезис с акцентной чертой |
| `![](img.png)` | картинка (с карточками — картинка слева) |
| `!!red Вывод` | плашка-вывод внизу слайда (`!!` — акцентный цвет) |
| `**жирный**`, `==акцент==`, `` `код` `` | внутри строки |
| `Note:` и дальше текст | заметки докладчика (попадают в pptx) |

Пример: `examples/demo.md`.
